> 本文件是 UI 改版的唯一标准。与本文档冲突的现有代码，一律以本文档为准。

## 2. 字体与字号（只有 4 档）

| 层级 | 字号/行高 | 字重 |
|---|---|---|
| 页面标题 | 16px / 24px | 500 |
| 区块标题、卡片标题 | 14px / 22px | 500 |
| 正文、表格内容 | 13px / 20px | 400 |
| 辅助信息（副标题、备注、单位） | 12px / 18px | 400 |

- 字重**只允许 400 和 500**：Tailwind 里只准用 `font-normal` 和 `font-medium`。**全站禁止 `font-bold` / `font-extrabold` / `font-semibold` / `font-black`。**
- 等宽字体（`font-mono`）**只允许**用于：违规编号、时间戳、数值、GPU/权重状态。中文一律不用等宽。
- 禁止全大写英文小标签（如 `INNOVATION 01`、`YOLOV11 MULTI-TASK` 的 `uppercase`）。

---

## 3. 间距（只有 4 档）

`8px / 12px / 16px / 24px`（Tailwind：`gap-2 / gap-3 / gap-4 / gap-6`）。
- 卡片内边距统一 `p-4`（16px）或 `p-5`（20px），同一页面内必须一致。
- 卡片之间统一 `gap-4`。
- 页面主容器上下内边距 `py-5`，左右 `px-6`。

---

## 4. 圆角与描边

- 卡片 `10px`（`rounded-[10px]`）；控件（按钮/输入框/下拉）`6px`；徽章 `4px`。列表项药丸可用 `rounded-full`。
- 所有边框：`1px solid var(--c-line)`，透明度不低于 0.9。
- **阴影只允许一条**：`0 1px 2px rgba(15,23,42,0.04)`。
- **严禁 `hover` 位移、缩放、发光**（现有的 `.card-luxury:hover { transform: translateY(-2px) }`、`.btn-silky:hover { transform: translateY(-1px); filter: brightness(1.04) }` 全部删除）。hover 只允许改变背景色或边框色。

## 6. 组件规则

### 6.1 卡片
- 统一类名 `.card`：白底、`1px var(--c-line)` 边框、圆角 10px、单层浅阴影、`p-4`。
- **删除** `card-soft` 和 `card-luxury` 两个类名，全项目替换为 `.card`。
  - 注意：`card-soft` 在当前项目中**从未被定义**（`main.css` 里只有 `card-luxury`），导致 `HistoryReview.vue`、`CameraDetect.vue` 的卡片实际没有白底和边框。这是必须修掉的 bug。
- 卡片**不做 hover 效果**（数据卡片不是可点对象）。

### 6.2 表格（用户每天要扫几十行，优先级最高）
- 行高固定 **48px**（`h-12`），`align-middle`。
- 表头：`12px / 400 / #64748B`，底色 `#F8FAFC`，**`whitespace-nowrap` 全部加满**，**`position: sticky; top: 0`**。
- 表体 `13px`。**所有"可能换行"的单元格加 `whitespace-nowrap`**；长文本（备注、地址）用 `truncate` + `title` 属性，禁止撑高行。
- 列宽必须显式声明，禁止依赖浏览器分配。违规台账页按下表执行（`table-fixed`）：

| 列 | 宽度 | 对齐 |
|---|---|---|
| 违规编号 | 130px | 左 |
| 捕获时间 | 140px | 左 |
| 监控点位 | 150px | 左 |
| 违规类型与判定 | 190px | 左 |
| 目标特征与车辆 | 180px | 左 |
| 判定可信度 | 84px | 居中 |
| 复核状态 | 110px | 左 |
| 复核人 / 备注 | 150px | 左 |
| 操作 | 110px | 居中 |

- **模型指标表**（mAP / FPS / 参数量 / 计算量等）统一**右对齐 + 等宽**，**不要**逐列涂不同颜色。只有"相对 Baseline 的增量"允许用语义色，绝对值一律用 `--c-ink` 或次级灰。
- **明确例外**：台账的「判定可信度」列**按 §6.3.1 上色**（分档 chip + 同色数字）。它与模型指标表性质不同 —— 前者回答"我要不要优先看这条"，是复核动线的一部分；后者回答"模型好不好"，绝对值本身不承载操作含义。这条例外是把原实现里已经存在的上色行为固化下来，不是新引入的。
- 行分隔用 `1px var(--c-line)`；hover 行底色 `#F8FAFC`。

### 6.3 徽章 / 状态标签
- 形态统一：`4px` 圆角、`px-2 py-0.5`、`12px / 400`、**单行不折行**（`whitespace-nowrap`）、**不用边框**（或统一 1px 同色系）。
- 状态映射（唯一裁决）：

| 状态 | 文字色 / 底色 |
|---|---|
| 待人工复核 | `#B45309` / `#FFFBEB` |
| 已确认入卷 | `#15803D` / `#F0FDF4` |
| 误报已剔除 | `#475569` / `#F1F5F9` |

- 违规类型映射（与状态色区分开，**不得共用红色**）：

| 类型 | 文字色 / 底色 |
|---|---|
| 单条违规（未按规定佩戴安全头盔、违法载人） | `#334155` / `#F1F5F9` |
| 双重违规（载人 + 未戴头盔） | `#B45309` / `#FFFBEB` |

### 6.3.1 判定可信度分档

色值与阈值的**唯一事实来源**是 `src/utils/confidence.js`
（后端对应常量在 `backend/app/services/stats_service.py` 的 `LOW_CONFIDENCE_THRESHOLD`，
两处必须同步）。展示层不得再各自硬编码阈值。

| 档位 | 阈值 | 文字色 / 底色 |
|---|---|---|
| 低 | `< 0.43` | `#B91C1C` / `#FEF2F2` |
| 中 | `0.43 – 0.62` | `#B45309` / `#FFFBEB` |
| 高 | `≥ 0.63` | `#15803D` / `#F0FDF4` |

台账里该列**只显示档位 chip（低 / 中 / 高）**，不显示百分比 —— 台账是"扫一遍决定先看哪条"
的分诊视图，档位已足够，精确到个位数对这个指标属于过度精度（该指标的测量本身就不那么细）。
具体百分比在 **hover 提示**与**详情弹窗**里给出，信息并未丢失。

> ⚠️ **为什么不是常见的 70 / 90**：本项目的「判定可信度」取的是**证据链中最弱环节**的
> 检测置信度（`rules.py` 的 `min()`），瓶颈在小目标 —— 头部在 1920 宽的卡口画面里往往
> 只有几十像素。实测 861 条真实抓拍：P25 = 43%、中位数 52%、P75 = 63%、**最高仅 71%**。
> 90% 以上根本不可能出现，沿用 70 / 90 会让 90% 的记录落进红档、颜色失去全部区分度。
> 因此按真实分布的**四分位点**标定。
> **若将来改动置信度的计算口径（例如改成加权融合），这两个阈值必须重新标定。**

### 6.4 按钮
只允许三档：

| 档位 | 样式 | 用途 |
|---|---|---|
| Primary | 实心 `--c-primary` + 白字，`h-8 px-3 rounded-md text-[13px]` | 每行/每屏**最多一个**，最高频操作 |
| Secondary | 白底 + `1px var(--c-line)` 边框 + `#334155` 字 | 导出、刷新、次级操作 |
| Danger ghost | 透明底 + `#B91C1C` 字，仅 hover 时浅红底 | 删除、剔除误报 |

- **导出按钮必须改为 Secondary**（现在是实心绿色，与"已确认"语义冲突，且比主流程按钮更抢眼）。
- 表格"操作"列按行状态切换：`待人工复核` → Primary「人工复核」；其余 → Secondary「调取证据」。
- 按钮内**不得出现 emoji**（`⚖️ 🔎 ⚡ ⭐ 🔄` 全删），需要图标就用 Element Plus 图标。

### 6.5 页面头部
- 层级只允许两层：**顶栏面包屑**（`交通违规监测系统 / 页面名`）+ **顶栏一行副标题**。
- 页面内容区**只保留一个区块标题**（如「违规检测历史记录与人工复核中心」），其后紧跟筛选控件，右侧放本轮操作按钮。
- 删除页面内的第二层 slogan（例如「全量违规事件台账、司法取证单与人工复核闭环」这类重复描述）。
- **删除**标题前的彩色小圆点（`w-2.5 h-2.5 rounded-full bg-indigo-600`）。
- **删除**侧边栏的 `Epoch 180` 徽标。侧边栏只保留一个真实的待办数字徽章（待复核数）。
